# Сводка по городу

CLI-утилита: получает текущую погоду в городе (Open-Meteo) и курс валюты к рублю (Frankfurter), применяет правила предобработки и печатает сводку.

## Установка

Нужен Python 3.12.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py --city Moscow
python main.py --city Moscow --currency EUR
python main.py --city Moscow --json
```

Пример вывода:

```
Город: Moscow
Погода: -3.2°C, clear sky
Тёплая одежда: да
USD→RUB: 92.15
Дорогой курс: нет
```

Флаг `-v` включает логи в stderr, у каждой записи есть `run_id` запуска.

## Правила предобработки

- температура ниже 0 °C — `warm_clothes: true`;
- курс выше 100 ₽ — `expensive: true`;
- пустое описание погоды заменяется на `no data`.

## Коды выхода

| Код | Значение |
|-----|----------|
| 0 | успех |
| 2 | ошибка аргументов |
| 3 | город или валюта не найдены |
| 4 | внешний сервис недоступен после повторов |

## Устройство

- `clients/` — запросы к API: timeout 5 с, два повтора при таймаутах, ошибках соединения, 5xx и 429 (с учётом `Retry-After`), проверка ответов. Курс кэшируется на 5 минут.
- `processing/` — правила и сборка сводки.
- `main.py` — аргументы, вывод, коды выхода.
